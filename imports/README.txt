Marketing Interview JSON Sets Q09 to Q17

Each JSON file is one separate One Quiz set.

Recommended learning order:
1. Study the Bullet Recall card first.
2. Practice the Verbatim cards one sentence at a time.
3. Use the memory hook only when needed.
4. For Q11, use the coworker story as the primary answer. Use the manager variant only when specifically asked.

These sets use semicolons for bullet-answer separation. The exact-sentence cards use short chunks for progressive typing practice.
